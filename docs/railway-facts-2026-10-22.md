## 环境规则

来源：[动车组网站耐候型分类](https://www.china-emu.cn/Trains/Type/Weather-Proof/)。
读取车型卡片实际展示的高寒、抗风沙和高海拔标记，保存为正向环境特征。
共 72 条启用车型规则补入环境条件，均包含高寒；没有修改原有速度、优先级、启停和备注。
型号主体以 G 结尾的车型继承高寒，括号内批次名称不影响主体判断；CRH5A 单独纳入。
CR400BF-GZ、GS、GX 等按网站明确标记补入，不采用“只有末尾 G 才高寒”的排他判断。
没有标记或没有资料的环境保持未知，不能推导为不耐高寒。
自定义环境条件与自动补充无法安全合并时保留原规则，并在导入报告列出冲突编号。

环境数组记录于规则来源快照，规则前提同步增加环境等于指定值的 AND 条件。
完整规则执行仍需全部前提；候选核验可以用少量已知事实筛选，并分别显示未知项。
浏览器以“系列 CRH5＋高寒”验证，返回包括 CRH5A、CRH5G 在内的 7 个有资料支持的候选。

## 重复执行

```bash
npm run data:weather
npm run data:build
npm run data:facts -- --base-id 2
```

第一条下载并缓存环境资料，第二条重建规则资料包，第三条备份并补全指定知识库。
补全使用事务，已有事实不会被覆盖，重复执行不会新增相同字段和值。
数据库写入结果见 `data/railway/facts-result.json`。
普通规则导入仍保留原有导入键和手工编辑；本次补全由独立命令更新可安全合并的环境条件。

已验证：16 项自动测试通过，生产构建通过；浏览器检查事实搜索、CRH5A 高寒条件、
系列与环境组合核验、实验记录和报告导出。报告实际写入本地目录。
